# 机器人上麦

## 接口

```
PUT /channels/{channel_id}/mic
```

1

## 功能描述

机器人在 `channel_id` 对应的语音子频道上麦。

音频接口：仅限音频类机器人才能使用，后续会根据机器人类型自动开通接口权限，现如需调用，需联系平台申请权限。

## Content-Type

```
application/json
```

1

## 参数

url参数：channel\_id
